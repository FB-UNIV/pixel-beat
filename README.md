# PIXEL BEAT

## Installation

1. install nvm : [nvm documentation](https://github.com/nvm-sh/nvm?tab=readme-ov-file#installing-and-updating) 
2. installation node version 25.2.0 `nvm install 25.2.0` 
3. `git clone https://github.com/BoujuFrancoisPro/pixel-beat.git`
4. `cd pixel-beat && mkdir public/assets`
5. `npm run start`

Access the UI in your browser at http://localhost:8000/

## Contributing
